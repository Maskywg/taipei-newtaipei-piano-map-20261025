# 雙北琴散步

台北與新北公共鋼琴指南，提供互動地圖、城市篩選、地點搜尋、樓層位置、開放資訊、Google 地圖導航與現場演奏影片。

- 台北：6 台鋼琴／5 個場域
- 新北：鶯歌車站、泰山國民運動中心，共 2 台
- 影片：3 段民眾演奏、1 段鶯歌車站活動紀錄，以及 KAWAI 官方轉分享連結
- 資料查詢日：2026-10-25；非完整名冊，未逐點到場確認

## 本機預覽

```sh
python3 -m http.server 8848
```

開啟 http://localhost:8848。

本頁使用 Leaflet / OpenStreetMap。影片以 YouTube 隱私增強模式在點擊後載入，另提供原始影片連結。地圖與影片需要網路連線。
